# Mini Racing 🏎️

Prototipo Android de carreras retro de 8 bits con la pista completa en pantalla horizontal.

## Estado
- Una pista ovalada, seis autos y cuatro oponentes CPU + uno controlado por IA provisionalmente.
- Aceleración automática; doblar izquierda/derecha con pantalla táctil o flechas.
- Derrape simplificado, pérdida de velocidad fuera de pista y colisiones con empujones.
- 5 vueltas.
- El multijugador por internet **todavía no está implementado**. El segundo auto es controlado por CPU de forma temporal.
- GitHub Actions intenta generar APK debug descargable desde Artifacts.

## Próximos pasos
1. Probar y mejorar físicas, CPU y conteo de vueltas.
2. Incorporar salas privadas con código y servidor autoritativo.
3. Arte pixelado, sonido, clasificaciones y pulido del APK.
